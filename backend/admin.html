Optional: Enable Supabase Storage Bucket

Photos ab bina bucket ke bhi permanent save hoti hain (Embedded WebP). Agar aap HD videos aur raw photos Supabase Storage CDN par upload karna chahein to Supabase Dashboard → SQL Editor mein yeh SQL ek martaba run karein: 

insert into storage.buckets (id, name, public)
values ('product-media', 'product-media', true)
on conflict (id) do update set public = true;

create policy "Public read product-media"
on storage.objects for select to public
using (bucket_id = 'product-media');

create policy "Public upload product-media"
on storage.objects for insert to public
with check (bucket_id = 'product-media');

create policy "Public update product-media"
on storage.objects for update to public
using (bucket_id = 'product-media');
